`asyncio.TaskGroup` cancels the remaining children when one child raises an ordinary exception such as `ValueError`. The non-cancellation failures are reported together in an `ExceptionGroup` when they are all ordinary exceptions. This happens after the `async with` block has waited for every child to finish.

Put cleanup in `try/finally` inside the child coroutines. Cancellation raises `asyncio.CancelledError` at the next opportunity. If you catch it explicitly, generally re-raise it after cleanup; swallowing it can interfere with the task group's cancellation machinery.

A child's `asyncio.CancelledError` alone does not trigger sibling cancellation. `BaseExceptionGroup` is used when the collected failures require it. `KeyboardInterrupt` and `SystemExit` are special: the group cancels and waits for the remaining children, then re-raises the original exception. No new tasks can be added after the first non-cancellation failure. This API requires Python 3.11 or later.
