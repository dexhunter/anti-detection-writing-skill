 Use ETags so clients can verify if their stored response can be reused. When a server sends JSON, they attach an ETag. Later, a conditional GET request includes that ETag. If the tag matches what has been selected, the server returns a 304 Not Modified status with no body. This means the client can reuse its stored body. If the tag doesn't match, the server returns a full success response of 200 OK along with the current JSON.

To avoid validation and reuse based on freshness instead, set an appropriate freshness policy like Cache Control: max age = 60.
