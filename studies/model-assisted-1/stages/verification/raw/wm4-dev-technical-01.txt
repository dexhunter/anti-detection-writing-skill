ETag enables receiving applications to validate whether cached representations may be reused. A server sends ETag with response and that tag value must be included in If-None Match header for future conditional GET requests. If the cached ETag matches a representation it reuses the cached one and returns 304 Not Modified, with no retransmission. If ETag does not match the server returns 200 OK with new response if further conditions are thereby satisfied. Still this includes sending a request. Application may employ freshness policy as Cache-Control max age = 60 as an example, in which case this reuse does not depend on caching validation. However reuse according to this is not a guarantee that relevant data has not changed for 60 seconds.
