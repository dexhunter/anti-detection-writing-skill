use an etag to let the client check whether its stored response can be reused. the server sends an etag with the json response, and a later conditional get includes that value in if-none-match. if the tag matches the selected representation, the server returns 304 not modified without a response body. this allows the client to reuse its stored body. if it does not match, a successful get returns 200 ok with the current json. this validation still involves a request. to permit reuse without validation, configure an appropriate freshness policy, such as cache-control: max-age=60, subject to the other caching rules. the cached response can then be reused while fresh. this does not promise that the underlying data will remain unchanged for 60 seconds.
