How to use Anti-Detection Writing Skill on your next draft

An AI draft can be accurate and still bury what the reader needs. Start with one reply, email or section of documentation. The skill gives your agent a repeatable way to identify the reader's needs, preserve facts, improve flow and review the edit. A GPTZero comparison is optional; a lower score is not guaranteed.

1. Install the skill.


Choose your agent in the installer. The default installation is for the current project.

2. Supply the context and original text.

Explain who will read it and what they need to do. For a technical reply, include the question, relevant documentation and version constraints. Then ask:

“Use $anti-detection-writing to make this text smoother and easier to read for [audience]. Preserve its facts, code and qualifications. Remove repetition and irrelevant background. Explain factual corrections, and get a separate review of the exact final text.”

A useful edit might move a prerequisite before an instruction, clarify an ambiguous pronoun or cut a repeated explanation. Check that the advice still means the same thing.

3. Measure the prose if needed.

“Compare the original and final explanatory prose using GPTZero Basic Scan, separately from code. Keep inline identifiers and values; exclude only code blocks and standalone commands. Use the same displayed model and save the exact inputs, all three confidences, dates and warnings. Keep unchanged and worse results too. Review the code and complete message separately for correctness.”

This prose-only request updates the published example; it does not change the scope of the historical results below.

Live scanning requires your own detector access and a browser tool your agent supports; the skill supplies neither. Assess correctness and readability separately from the score.

What the development examples show

On September 6, 2026, a fresh recheck of one saved Qwen Code reply pair returned 100% AI / 0% mixed / 0% human → 1% AI / 99% mixed / 0% human in GPTZero Basic Scan, Model 4.9b. The screenshots show those completed scans, not scores for this article. This repeated a development case; it was not a new test of the packaged skill.

Only one short, relevant quotation from the asker was added; the answer body stayed identical. Both content and length changed, so this does not establish a rewriting benefit. A 99% mixed result does not mean 99% human, and lower AI confidence does not establish human authorship.

In that dated development sample, 5 of 10 quotation comparisons reduced AI confidence, compared with 0 of 15 plain rewrites. Separate LLM reviewers rated eight plain revisions clearer and seven equivalent; these were not human preference ratings. The observations came from completed UI scans. The current packaged skill has not yet been prospectively validated for reliable detector performance.

Use a quotation only when it helps answer the question. Keep a clear, correct edit even if the score is unchanged, subject to your publication requirements.

Try one draft and share what improved or fell short in Discussions. The repository includes exact inputs, measured examples and unsuccessful cases.
