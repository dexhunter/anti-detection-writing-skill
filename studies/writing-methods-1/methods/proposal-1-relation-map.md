# Proposal 1: Compose from a nonprose relation map

Scope: input preparation plus drafting. Both arms use the same frozen installed writing skill. This is a workflow comparison, not an isolated skill-bullet test. No detector benefit is established.

Preparer procedure:

Create a relation table from the original and complete factual contract. Preserve the exact question, reader context, code, commands, identifiers, numbers, units and URLs. For each required relation record its ID, actor or subject, event or action, effect or object, condition, timing, scope, modality, exception, source IDs and protected-span IDs. Use short noun/verb fragments or explicit relations rather than grammatical explanatory sentences. Empty fields mean no supplied value, not a negative claim. Preserve logical dependencies and uncertainty. Group by subject for lookup using stable IDs; this order is not the answer outline.

Keep editorial cautions in separate guard notes mapped to the semantic facts that satisfy them. If a caution contains unique substantive meaning, encode that meaning as a required relation as well. Reconcile the table against both the original and factual contract before the writer sees it: no claim or useful qualification may be dropped for this comparison. Save the reconciliation. Do not show the original paragraphs or prose claim ledger to the variant writer. Keep them available to the independent reviewer.

Exact writer instruction:

Write one complete answer to the supplied question using the relation map. The map records meaning; its row order and field labels are not an answer outline. Decide how the reader can follow the explanation, then compose the prose without turning each row into a sentence. Express each condition or exception where it changes the described action or result. Preserve every required relation, its actor, scope, timing, modality and negation, and all protected text. Editorial guard notes are checks on your wording: satisfy them through accurate claims rather than explaining the checks to the reader. Use only the supplied facts. Save the answer and a separate mapping from required relation IDs to the passages that express them. Do not add quotations, personal experience, invented context, mistakes, invisible characters or padding. Produce one final answer; no detector feedback or post-submission rewrite is available.

Apply the supplied frozen writing skill to this reconstruction task. The question and reconciled relation map are your writing input; the original is intentionally unavailable. All skill requirements for factual accuracy, reader relevance and faithful protected text remain active. Do not edit the skill.
